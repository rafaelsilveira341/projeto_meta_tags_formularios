Atributos de Formulário HTML























Resumo dos atributos

Atributo Função
actionDefine o destino do envio.
targetDefine onde abrir a resposta.
methodDefine GET, POST etc.
autocompleteControla sugestões/preenchimento automático.
valueDefine valor inicial.
readonlyPermite visualizar, mas não editar.
disabledDesativa o campo.
sizeDefine tamanho visual de campo de texto.
maxlengthLimita a quantidade de caracteres.
min / maxDefinem limites mínimo e máximo.
multiplePermite múltiplos valores quando suportado.
placeholderMostra uma dica no campo vazio.
requiredExige preenchimento.
autofocusColoca o foco inicial no campo.
